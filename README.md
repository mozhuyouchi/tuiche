# 推车管理工具

一个动漫谷子团购「推车/配比」管理系统，帮助团长管理排表、追踪推车记录、自动分配捆物。

在线地址：`http://47.98.108.88/car/`

## 使用说明

### 团长端

**首次配置：**
1. 打开 `http://47.98.108.88/car/admin.html`
2. 输入**团号**（自定义，如 `renji0602`）和**管理密码**
3. 点击「进入管理端」
4. 之后再次打开会自动登录，无需重复输入

**导入排表：**
1. 点击上传排表文件（支持 XLSX / CSV / TXT）
2. 系统自动识别款式、分类、单价
3. 逐个确认每款的捆序（捆2 / 捆1 / 备捆 / 不捆 / 捆物）
4. 点击「导入并覆盖成员」

**管理推车记录：**
- 查看所有团员的推车提交
- 点击「通过」或「未通过」审核记录
- 点击「编辑」修改记录内容
- 点击「删除」移除记录（需确认）
- 每条记录显示相对时间（"3 分钟前"）

**分配捆物：**
- 切换到「分配结果」标签页
- 筛选捆序类型
- 勾选/取消「已带余」排除不需要上捆的人
- 点击「上捆」随机分配
- 点击「导出」下载 CSV

### 团员端

**首次配置：**
1. 打开 `http://47.98.108.88/car/member.html`
2. 输入**团号**（向团长索要）
3. 点击「连接」
4. 之后再次打开会自动登录

**提交推车：**
1. 输入你的 cn（昵称），排表导入后会有下拉提示
2. 选择申报类型（有效推车 / 无效推车）
3. 填写被推来的人的 cn（有下拉提示）
4. 填写凭证说明，可上传截图
5. 点击「提交推车记录」

**确认被推：**
- 在「需要我确认」区域查看别人对你的推车申报
- 点击「确认是 TA 推来的」或「不是 TA 推来的」

**管理自己的记录：**
- 在「我提交的记录」区域查看、编辑或删除自己的记录

## 技术架构

```
浏览器 → Nginx (端口 80)
  ├── /car/          → 静态网页 (/var/www/html/car/)
  ├── /car-api/*     → Node.js API (127.0.0.1:3000)
  └── /car-uploads/  → 上传的截图 (/srv/car-api/uploads/)
```

| 层 | 技术 |
|----|------|
| 前端 | 纯 HTML/CSS/JS，无框架 |
| 后端 | Node.js 原生 HTTP，零依赖 |
| 数据库 | 服务器本地 JSON 文件 |
| 反向代理 | Nginx |

## 代码更新记录

### 2026-06-04 自建后端部署

**部署方式：**
- 原项目使用 Supabase 云端数据库，改为自建 Node.js 后端部署在阿里云
- 数据存储：Supabase → `/srv/car-api/car-states.json`
- 新增 `server/aliyun-server.js` 作为 API 服务
- Nginx 配置 `/car-api/` 反向代理到 Node.js 3000 端口
- 原有 Supabase 数据（renjizuidiao 团，70 成员，13 条记录）已迁移到自建服务器

**图片存储改造：**
- 原方案：截图以 base64 编码存在 JSON 中，体积膨胀，localStorage 易满，超过 2MB 无法上传
- 新方案：截图上传为独立文件存于服务器 `/srv/car-api/uploads/`，JSON 只存文件路径
- Nginx 直接提供图片，支持最大 50MB 上传
- 新增图片预览弹窗（点击缩略图弹出大图），替代原 `target="_blank"` 方式
- 原有 7 张 base64 截图已自动迁移为服务器文件

**免连接自动登录：**
- 原方案：每次打开页面需手动输入团号点击「连接」
- 新方案：首次配置后凭证保存到 localStorage，后续自动连接
- 页面直接显示主内容，顶部显示「当前团号：xxx [切换] [退出]」
- 支持切换团号和退出清空配置

**编辑与删除功能：**
- 团长端每条记录新增「编辑」和「删除」按钮
- 团员端自己的记录新增「编辑」和「删除」按钮
- 编辑支持修改：申报类型、被推人、凭证说明
- 修改后自动同步到服务器，两端一致

**UX 优化：**
- 团员端昵称和被推人输入框增加自动补全（datalist），列出排表内所有成员名字
- 每条推车记录显示相对时间（"刚刚"、"5 分钟前"、"2 小时前"）
- 60 秒自动刷新，多端数据保持同步
- 团长端「实时总览」新增「待审核」计数
- 分配结果页新增「导出 CSV」按钮
- 错误提示改为显示服务器具体原因（不再笼统"连接失败"）
