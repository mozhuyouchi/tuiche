# 推车登记与捆物计算

这是一个本地网页小程序原型，已经拆成两个前端页面。

## 页面

- `index.html`：入口页
- `admin.html`：团长 / 管理端，看全数据
- `member.html`：团员端，只提交和确认自己的内容

## 共用数据库

当前原型用浏览器本地存储模拟共用数据库，代码在 `db.js`。两个页面读写同一个数据源。

正式上线时，可以把 `db.js` 里的本地存储换成云数据库，例如微信云开发、Supabase 或自己的后端。

## 当前规则

- 捆2 默认捆 2，捆1 默认捆 1，备捆和不捆默认不捆
- 已确认的有效推车减 1
- 已确认的小推车多减 2
- 无效、待确认、争议不减
- 最低捆 0

## 排表导入

团长端支持上传导入：

- 上传 XLSX / CSV / TXT 排表文件

上传 Excel 后会识别“分类 / 种类 / 单价 / 昵称 / 数量”，并按单价从高到低展示款式。团长确认每个款式的捆序：捆2、捆1、备捆或不捆，再导入成员。

## 怎么打开

双击 `index.html`，再选择团长端或团员端。
